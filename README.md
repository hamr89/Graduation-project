# University Bus Tracking mobile application
University transportation systems face a lot of operational challenges like lack of real-time visibility, inefficient attendance tracking, and poor communication between students and drivers.
This project was developed to address these challenges and provide solutions to improve university transportation process.

## Application's functionality

### Student's module
-Live tracking for bus's location and estimated arrival time
-Ability of recording daily attendance status
-Changing pickup point
-Emergency reporting system

### Driver's module
-Navigate the route with the pickup points to path through
-Alternative routing system 
-Student's attendance list based on attendance records 
-Contact the manager in case of emergency

### Manager's module
-Bus live tracking
-Viewing problem reports submitted by students to take actions


## Tools used
-Flutter & Dart
-Firebase Auth
-Cloud Firestore
-OpenStreetMap
-OSRM


The live GPS updates from the driver's phone and broadcasts instantly to students' navigation map side. The routing system fetches multiple route options from OSRM and allows the driver to pick the most suitable route. Attendance syncs instantly through the databse and shows a list with the students commited to the bus-line, allowing the driver to confirm them being on-board.
